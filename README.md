# Chunking Lab: Text Chunking and Document Processing for RAG

A 45-minute self-paced interactive lesson.

## Run
Open `index.html` in any modern browser. No install, no internet needed.

## Flow
1. Why chunk (5 min)  2. Playground (12)  3. Retrieval challenge (12)  4. Build it in Python (6)  5. Quiz (6)  6. Real-world use (4)

## Notes
The challenge uses keyword scoring as a simplified stand-in for embedding similarity so results are instant and offline.
